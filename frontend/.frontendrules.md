# MemoryBun Frontend - Style Guide & Cursor Rules

## Scope
**These rules apply specifically to the `frontend/` directory and all React/TypeScript frontend code.**
This is a React frontend application for the MemoryBun spaced repetition learning platform.

---

## Project Structure

### Directory Organization
```
frontend/src/
├── components/           # Reusable UI components
│   └── ui/               # Base UI primitives (button, avatar, input, separator)
├── screens/              # Page-level components (each screen = one route)
│   ├── QuestionMenu/     # Landing page with question list
│   ├── QuestionSample/   # Practice question view
│   └── SummaryReport/    # Post-session report view
├── config/               # Static configuration files
├── lib/                  # Utility functions and helpers
├── services/             # API service layer
└── types/                # TypeScript type definitions
```

### Screen Folder Structure
Each screen follows this pattern:
```
ScreenName/
├── ScreenName.tsx        # Main screen component (page layout)
├── index.ts              # Export file - exports the screen component
└── sections/             # Section components specific to this screen
    ├── SectionOne.tsx    # A section of the screen
    ├── SectionTwo.tsx    # Another section
    └── index.ts          # Barrel export for all sections
```

**Example: QuestionMenu**
```
QuestionMenu/
├── QuestionMenu.tsx      # Main component with header + sections
├── index.ts              # export { QuestionMenu } from "./QuestionMenu"
└── sections/
    ├── WelcomeBackSection.tsx
    ├── QuestionListSection.tsx
    ├── QuestionListTable.tsx
    └── index.ts          # exports all section components
```

### Section index.ts Pattern
```typescript
export { SectionOne } from "./SectionOne";
export { SectionTwo } from "./SectionTwo";
```

### Component Function Pattern
All components use arrow function syntax with explicit JSX.Element return type:
```typescript
export const ComponentName = (): JSX.Element => {
  return (
    <div>...</div>
  );
};
```

## Typography

### Font Family
- **Primary**: `font-sans` (default Tailwind sans-serif stack)
- **Display/Headings**: `[font-family:'Source_Serif_Pro',Helvetica]` (WelcomeBack section only)

### Responsive Font Sizes
Use this pattern for responsive typography: `text-{size} 2xl:text-{larger-size}`

| Element | Default | 2XL Breakpoint | Class Pattern |
|---------|---------|----------------|---------------|
| **Page Title (Header)** | `text-xl` | `text-2xl` | `text-xl 2xl:text-2xl` |
| **Section Title (Large)** | `text-2xl` | `text-3xl` | `text-2xl 2xl:text-3xl` |
| **Section Title (Medium)** | `text-lg` | `text-xl` | `text-lg 2xl:text-xl` |
| **Subsection Title** | `text-lg` | - | `text-lg font-semibold` |
| **Body Text** | `text-sm` | `text-base` | `text-sm 2xl:text-base` |
| **Small Text/Labels** | `text-xs` | - | `text-xs font-medium` |
| **Table Content** | `text-sm` | `text-base` | `text-sm 2xl:text-base` |

### Font Weights
| Weight | Class | Usage |
|--------|-------|-------|
| Bold | `font-bold` | Major headings (Performance Summary, Welcome) |
| Semibold | `font-semibold` | Section titles, active states, important labels |
| Medium | `font-medium` | Labels, table headers, buttons |
| Normal | (default) | Body text |

### Text Styling Examples
```typescript
// Large section heading
<h2 className="text-2xl 2xl:text-3xl font-bold text-black mb-6">

// Medium section heading with icon
<h2 className="text-lg font-semibold text-black">

// Body text
<div className="text-sm 2xl:text-base text-gray-900">

// Label text (uppercase)
<div className="text-xs font-medium text-gray-600 mb-1">LABEL</div>

// Table header
<div className="text-[#001d58] font-medium text-sm 2xl:text-base">
```

## Math Rendering

### Configuration
Use **react-katex** with **KaTeX** for math expressions:
```typescript
import { InlineMath } from "react-katex";
import "katex/dist/katex.min.css";
```

### Inline Math Syntax
Wrap math expressions in `$...$` in content strings:
```typescript
const text = "Calculate $\\sin(x)$ when $x = 0$";
```

### Rendering Helper
Use the `renderTextWithMath` utility from `lib/mathUtils.tsx`:
```typescript
import { renderTextWithMath } from "../../../lib/mathUtils";

// Usage
<p>{renderTextWithMath(textWithMath)}</p>
```

## Key Principles

1. **Responsive First** - Always consider mobile and 2XL breakpoints
2. **Consistent Colors** - Use the defined color palette, prefer `#0053FA` for primary blue
3. **Lucide Icons** - Use Lucide React for all icons
4. **Type Safety** - Use TypeScript with explicit types
5. **Component Isolation** - Keep sections self-contained within their screen folder
6. **Barrel Exports** - Use index.ts for clean imports

---

## What NOT to Do

- ❌ Don't use raw hex colors not in the color scheme
- ❌ Don't use custom SVG icons when Lucide has an equivalent
- ❌ Don't hardcode font sizes without responsive variants
- ❌ Don't put section components in the wrong screen folder
- ❌ Don't forget the `2xl:` responsive breakpoint for text sizes
- ❌ Don't use `class Config:` pattern (use modern patterns)
- ❌ Don't import icons from multiple icon libraries
